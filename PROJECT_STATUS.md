# Project Status

This repository is the initial project structure for the Snapdragon AI Lab challenge.

## Implemented in this starter repository
- ESP32 sensor-counting prototype
- Sample production dataset
- Basic anomaly-detection training script
- Basic inference script
- Streamlit dashboard skeleton

## Next development steps
1. Integrate the actual ESP32 hardware and Wi-Fi communication.
2. Collect real production data.
3. Train and evaluate the AI model using real data.
4. Add tested local inference on the Snapdragon-powered HP PC.
5. Measure latency and model performance.
6. Add screenshots, hardware photographs and final results.
