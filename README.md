# AI-Powered Intelligent Production Monitoring and Predictive Maintenance System

## Snapdragon AI Lab Build & Present Challenge 2026

This project combines an ESP32-based production monitoring system with an AI application intended to run on a Snapdragon-powered HP AI PC.

### Project Goals
- Real-time production counting using optical/IR sensors
- Wi-Fi data transmission from ESP32 to a PC
- AI-based anomaly detection on production data
- Predictive downtime alerts
- Real-time monitoring dashboard
- Future optimization for Snapdragon on-device AI/NPU capabilities

### System Architecture
IR/Optical Sensors → ESP32 → Wi-Fi → Snapdragon-powered HP AI PC → AI Model → Dashboard & Alerts

### Repository Structure
- `esp32/` - ESP32 firmware
- `ai/` - AI training and inference code
- `dashboard/` - monitoring dashboard
- `data/` - sample data
- `docs/` - project documents
- `images/` - project images

> Note: Snapdragon/NPU optimization should only be claimed after it has been implemented and tested on the target hardware.
